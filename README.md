# Les Viandes Maska preview

Prebuilt static deployment artifact for the dedicated Render service `les-viandes-maska`.

- Public design preview; noindex is intentional.
- No form endpoint, analytics, tracking, credentials or customer datastore.
- Source, approvals and QA evidence are maintained in the TierX client workspace.
- `render.yaml` is copied from the client release manifest by `src/package-deploy.cjs`.
- Do not edit generated files in this repository directly. Rebuild and repackage the client artifact.
